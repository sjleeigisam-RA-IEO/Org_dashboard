# 자산-펀드-프로젝트 표시 모델 제안

## 원칙

- 검색 결과에는 사용자가 선택한 명칭의 성격을 먼저 보여준다: 자산, 펀드/비히클, 프로젝트, 수익자, 대주.
- 이름이 펀드/비히클에서 온 경우에도 검색 결과에 가짜 자산명처럼 중복 노출하지 않는다.
- 클릭 후 drawer에서 관계를 푼다. 목록이 1개면 바로 상세로 들어가고, 2개 이상이면 선택 리스트를 먼저 보여준다.
- 실물자산은 주소, PNU, 좌표, 건축물대장 상태를 전면에 둔다.
- 증권성/재간접/포트폴리오형 자산은 위치 지도보다 하위 보유목록, 전략, 관계 펀드를 먼저 보여준다.

## 엔티티별 클릭 동작

| 클릭 대상 | 1차 drawer 제목 | 1차 내용 | 다음 액션 |
|---|---|---|---|
| 자산 | 자산 상세 | 연결 펀드, 프로젝트, 위치/PNU/건축물대장, 운용상태 | 연결 펀드/프로젝트 선택 |
| 펀드/비히클 | 펀드 상세 | 하위 자산 리스트, 프로젝트 리스트, 수익자/대주 | 자산이 여러 개면 자산 리스트 drawer |
| 프로젝트 | 프로젝트 상세 | 관련 자산 리스트, 관련 펀드 리스트 | 자산/펀드 중 선택 |
| 수익자 | 수익자 투자 현황 | 투자 펀드 리스트, 연결 자산 리스트 | 펀드 또는 자산 상세 |
| 대주 | 대주 익스포저 | 대출/채권 연결 펀드, 담보/기초자산 | 펀드 또는 자산 상세 |

## 자산 표시 유형

| asset_semantics | 화면 표시 | 지도/PNU | 대표 예시 |
|---|---|---|---|
| `underlying_asset` | 실물 자산 상세 | 표시 | 경산 쿠팡물류센터, 부산송정물류센터, 오시리아타워레지던스 |
| `security_or_portfolio_asset` | 포트폴리오/증권성 자산 상세 | 기본 숨김 | Global REITs(삼성OCIO), Global REITs(셀렉리츠1호) |
| `security_or_portfolio_asset_list` | 보유 항목 목록 | 기본 숨김 | 공모주, 상장리츠, 회사채 묶음 |
| `fund_interest_or_indirect_asset` | 재간접 투자대상 상세 | 기본 숨김 | ARDIAN Infrastructure Fund VI |
| `fund_interest_or_indirect_asset_list` | 재간접 하위 펀드 목록 | 기본 숨김 | Pantheon Viking Co-Invest LP, NMP V 등 |
| `vehicle_or_share_class_asset` | 비히클/종류주 안내 + 연결 기초자산 | 연결 자산 기준 | 572호 1종 |
| `vehicle_or_restructured_pf_asset` | 재구조화/PF 비히클 상세 | 연결 자산 기준 | 용산PF 재구조화 |

## Drawer 구성

### 실물 자산 drawer

1. 헤더: 자산명, 자산유형, 운용상태, 국내/해외
2. 위치: 주소, 지도 좌표, PNU, 건축물대장 조회 상태
3. 물리 정보: 연면적, 대지면적, 용도, 층수, 준공일
4. 관계: 연결 펀드, 프로젝트, 대주, 수익자
5. 데이터 상태: 원천, confidence, 업데이트 필요 여부

### 펀드/비히클 drawer

1. 헤더: 펀드명, 약칭, 펀드코드, 상태
2. 하위 자산 리스트: 자산명, 유형, 주소/PNU 유무, 관계유형
3. 프로젝트 리스트
4. 수익자/대주 리스트
5. 자산이 2개 이상이면 리스트에서 자산 클릭 시 자산 drawer로 전환

### 프로젝트 drawer

1. 헤더: 프로젝트명, 프로젝트 유형, 상태
2. 관련 자산 리스트
3. 관련 펀드/비히클 리스트
4. 프로젝트가 펀드명에서 생성된 pseudo project인지 표시

## 검색 결과 카드 규칙

- 같은 명칭이 펀드명과 자산명에 동시에 있으면 펀드/비히클 결과를 우선 노출한다.
- `asset_name`이 fund-derived fallback이면 자산 결과는 숨기고, 펀드 drawer 안의 하위 자산 리스트에서 풀어 보여준다.
- `underlying_asset`은 자산 결과로 직접 노출한다.
- `security_or_portfolio_asset*`, `fund_interest_or_indirect_asset*`는 자산 결과로 노출하되 지도 아이콘 대신 포트폴리오/재간접 뱃지를 붙인다.

## 이번 정비 결과 적용

- 자산명 후보는 전부 채택 완료: 수동 잔여 0건.
- 실물 단일 후보는 기존 `asset_master` 이름/위치 업데이트 후보로 관리한다.
- 다자산 펀드 후보는 기존 대표 asset_id에 PNU를 덮어쓰지 않고, 하위 자산 생성/연결 후보로 관리한다.
- 태양광 392호/435호처럼 하위 자산이 많은 펀드는 펀드 drawer에서 자산 리스트를 기본 화면으로 보여준다.
