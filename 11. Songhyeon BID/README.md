# 송현BID 포트폴리오 펀드 운용 대시보드

동일 투자자가 송현 권역의 복수 자산을 하나의 포트폴리오 펀드로 보유한다는 가정 아래 만든 정적 의사결정 프로토타입입니다.

## 공개 범위

- `index.html`: 외부 런타임 의존성이 없는 단일 파일 대시보드
- `REFERENCE_AND_DESIGN.md`: 국내외 레퍼런스 및 적용설계
- `qa-report.json`: Edge 데스크톱·모바일 회귀 QA 결과

## 중요

- 모든 수치는 **DEMO / SIMULATED**입니다.
- 실제 투자위원회 자료나 펀드 실적이 아닙니다.
- 실제 적용에는 펀드 회계, PM, 임대차, POS/PG, CRM, 이동데이터 및 계약 registry 연결이 필요합니다.

## 검증 범위

- Desktop 1440×1000
- Mobile 390×844
- 콘솔 오류·실패 요청·외부 런타임 요청 0
- body 가로 overflow·중복 ID 0
- 키보드 drawer·dialog·포커스 복귀 검증
- 기준 NOI 118.4억원, 순증 7.6%=9.0억원, 결과 127.4억원 canonical 대사
