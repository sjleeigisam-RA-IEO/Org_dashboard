## 4. 저장 모델

```text
sale_process
  ├─ sale_process_role: SELLER / SELL_SIDE_ADVISOR / BUY_SIDE_ADVISOR ...
  ├─ bid_round
  │    └─ bidder_participation
  │         ├─ consortium_member
  │         └─ bid_submission
  │              └─ funding_component
  ├─ bid_decision: SHORTLIST / PREFERRED / RESERVE / NOT_SELECTED
  └─ transaction_milestone: MOU / SPA / BALANCE_PAID / OWNERSHIP_TRANSFER /
                              CLOSED / FAILED / WITHDRAWN / REBID
```

각 가격에는 `amount type`, `comparator`, `reported rank`, `round`, `source claim`을 붙인다. 자금은 펀드·LP equity·리츠·SPC·브리지/인수금융·대주를 분리하고 `RUMORED/PLANNED/COMMITTED/EXECUTED` 상태를 둔다.

## 5. 남는 정보 공백

- 모든 입찰자의 개별 제출가격과 정식 순위는 공개되지 않는 경우가 대부분이다.
- “차순위”는 가격 2위 보도와 공식 reserve bidder 지정을 구분해야 한다.
- 운용사 이름만으로 특정 블라인드펀드·LP·인수금융을 추정하지 않는다.
- 포트폴리오/결합 펀드 자금은 개별 자산에 임의 배분하지 않는다.
- 우협 보도만 있는 TCC동양타워, SPA만 확인된 SI타워, 계획만 나온 죽전은 종결로 승격하지 않는다.
- 비공개 IM·데이터룸·입찰서·대출약정서가 있어야 채울 수 있는 필드는 공개조사에서 `미공개/미확인`으로 남는다.
