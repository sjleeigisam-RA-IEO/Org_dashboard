6. Dedupe and Display Rules

Asset root

같은 표시 자산은 assetDisplayGroupKey()로 접고, (투자) suffix는 표시명에서 제거합니다.

Broad query

분당, 홈플러스, 물류 같은 넓은 검색어도 하나의 topic 카드가 아니라 실제 표시 대상별 card로 나눕니다.

Same location

같은 주소/PNU의 비직접 row는 별도 root로 띄우지 않고 visible physical asset의 relationship hint로 흡수합니다.

Numeric

1-4자리 숫자는 fund/project code 중심으로 제한해 asset noise를 줄입니다.
